# Itool 1.3

Windows用圧縮ファイルを解凍し、Itool.exeを実行してください。_internalは同じ場所に残します。初回に言語を選択でき、上部から変更できます。日本語用起動ファイルもあります。

対応するI Wanna Maker、jtool 1.3.6 GMS1 VM、tuhkakuppi 5.2 GM8.1/GMSは座標・通常床のya解析・手順照合に対応します。I wanna Lap Around 1.1を含む標準的な32bit GMS1 VMのI-wannaゲームも、互換性確認後に通常床の解析と手順照合を利用できます。整数倍に拡大した矩形ブロックにも対応します。独自の物理・スクリプト、汎用GMS2、他のYYC/64bit、未対応GM8は保証しません。座標記録後の案内をご確認ください。

ゲームのステージを開いてから起動します。検出が1件なら自動選択、複数なら接続先を選びます。「プロセスを選択」から手動変更もできます。エンジン名は機能タブの右側に表示します。

通常の床で静止し「現在の座標を記録」、目標yaを入力して解析します。候補を選び、右の手順に従ってください。ジャンプ後に静止すると着地yaを照合し、一致は緑、相違は赤で表示します。R後の着地値が完了済み手順に一致すれば、そこまでの緑表示を保ち、次の手順から続けます。初期位置なら最初から待機します。同じ値が複数あれば最後に一致する完了手順を使います。「最初から照合」で手動リセットもできます。異なる場所やステージでは再記録・再解析してください。入力操作全体を検証するものではありません。

未接続時は目標を入力するだけでオフライン解析になります。開始Yは309.399993896484375です。実機手順の自動完了は行いません。

4fはjtool基準のフレーム数です。地上ジャンプの間は着地します。1+3は最初のキャンセルから3フレーム後に次のキーを離す表記です。複数のジャンプキーを改キーソフトで用意してください。2段目は空中待機の表示に従います。

フレーム、キャンセル、誤差、順序を左側で設定できます。初期値は100件で自動停止、0は手動停止です。ホイールは設定欄をスクロールするだけです。水・壁ジャンプ・動く床・特殊重力・遮蔽物などでは画面の対応案内に従ってください。
標準GMSゲームで頭上に認識済みの静止ブロックや針がある場合、その範囲に入らない手順のみ表示します。危険な2段ジャンプは候補から除かれる場合があります。

座標・解のコピーとファイル出力ができます。Itoolにフォーカスがある時、F6は記録、F7は解析/停止、F8はコピーです。マップソルバーは開発中です。
「謝辞」タブで、ご協力くださった方々とその内容を確認できます。
