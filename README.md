# Itool

Itool 是面向 I wanna 关卡分析与 TAS 路线研究的 Windows 桌面工具，支持 GM8、GMS 和 I Wanna Maker（IWM）三种引擎，集地图编辑、路线求解、物理分析与录像回放于一体。

[下载最新正式版](https://github.com/frredomerror91-netizen/Itool/releases/latest) · [更新记录](CHANGELOG.md) · [SHA-256 校验](SHA256SUMS.txt)

## 主要功能

- **地图编辑与导入**：编辑物件、查看碰撞范围，导入地图文件或读取受支持游戏进程中的当前房间，保存为 Itool 工程。
- **路线求解**：提供粗略、精细两种模式，支持从出生点或试玩暂停状态搜索路线，并配置跳键数量、跳长与多键取消等条件。
- **路线优化**：支持持续改短、多种跳法与选段重搜，可比较方案、查看逐帧按键并导出路线。
- **YA 分析**：计算一段跳、二段跳与多键取消组合，分析固定路线、任意走法及指定起跳状态的可行 YA 区间。
- **试玩与录像**：按所选引擎试玩和回放，支持暂停、变速、逐帧查看、录制与续录，以及自定义键位。
- **地图转换**：支持 Itool、Jtool、I Wanna Maker 与 RMJ 地图格式，提供房间预览、转换前后对照和物件筛选。

## 运行环境

Windows 10 / 11 x64，提供便携版与内置更新功能。
