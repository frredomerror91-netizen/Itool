# Itool

Itool 是面向 I wanna 关卡分析与 TAS 路线研究的 Windows 桌面工具，支持 GM8、GMS 和 I Wanna Maker（IWM）三种引擎。可以读取或编辑地图、搜索路线、逐帧回放，也可以单独计算达到指定 YA 所需的跳法。

## v2.1.5 正式版（R3）

新版改进从出生点贴墙取得 XA，以及水、固定单向平台和引擎 Warp 的路线搜索；增加滚轮选择刺向和转换前后对照预览，修复藤蔓与通关后的重生、松键再重生的输入处理。


可行方案旁的「选段重搜」可标记 A、B 重新搜索局部，并从原入口核验整条路线；实际缩短后才收入新方案。水和平台等物件的支持范围仍取决于所选引擎。搜索超时表示预算内未找到路线，不表示无解。

## 地图路线求解

1. 在「地图求解器（beta）」新建地图或打开已有的 `.itmap` 工程。选定引擎、边界和起点，再指定完成条件。可以手摆目标区域，也可以选择对应引擎的终点物件。房间内有多个终点物件时，触碰其中任意一个即可完成。Maker 的普通编号传送器用于房内移动。
2. 点击「粗略求解」从出生点查找路线，也可以先试玩，在当前帧暂停后开始求解。后者会保留角色的位置、速度、跳跃资源与持键状态。粗略和精细两档分别保存搜索时限、跳键数量、允许的跳长及多键取消等参数。
3. 在「可行方案」里选中一条路线，可以回放、查看逐帧按键或导出为 JSON。每条路线都经过所选引擎从任务入口逐帧回放。点击「继续改进」可尝试缩短路线。「已知最短」表示当前已验证方案中的最少帧数。搜索达到时限仍未找到路线时，可达性仍未确定。

## 地图编辑与导入

- **编辑与试玩。** 可以摆放物件、查看碰撞范围，也可以暂停、变速或单帧推进。从「查看任务地图」列表悬停预览各个任务的地图，双击可恢复任务开始时的快照。
- **读取游戏进程。** 在顶栏点击「选择进程」，再到「地图」页点击「从游戏读取当前地图」。当前支持经过核验的 Jtool GM8、Jtool GMS 和 I Wanna Maker 版本，导入后可编辑、另存和试玩。状态栏会显示跳过的实例数。动态机关、自定义事件和跨房逻辑的导入范围取决于具体物件与模板。
- **转换地图文件。** 地图转换器支持 Jtool `.jmap`、I Wanna Maker v104 和 RMJ 1.03 `.map`。按房间预览物件、校正起点与目标，再保存为 Itool 工程。转换器会列出尚未支持的物件或跨房事件。

## YA 求解与区间分析

YA 表示角色纵坐标的小数部分。在「ya 求解」中指定引擎、起始坐标、目标 YA 和允许误差，可计算满足条件的一段跳、二段跳与多键取消组合。起点支持手动录入，也可从受支持的游戏进程采样。结果列出各跳段的持续帧数、松键时机及到达 YA。

| 分析项 | 固定条件 | 结果 |
| --- | --- | --- |
| 本解 YA | 选中路线的逐帧输入 | 这组输入可以通关的起始 YA 区间 |
| 任意走法 YA | 同一地图、起点条件和输入范围 | 已找到可行走法的起始 YA 区间，可查看各区间对应的输入 |
| 起跳 YA | 选定起跳帧的速度、跳跃资源、持键状态及后续输入 | 保持该路线后半段时允许的起跳 YA |

区间标为「站稳」时，入口取角色落定后的状态。如果路线在出生当帧就按跳，应从出生帧回放验证。界面分别标示原事件已验证区间、模型推算区间和未判定范围。

## 按键、录像与回放

在「角色」或「求解」页打开「键位设置」，可以绑定左右移动、左右微调、射击及四个跳键。路线中的 J1 至 J4 表示逻辑跳键。更换实体键后仍可按原动作回放旧录像。内置试玩支持录制、沿时间轴定位、逐帧检查，以及从指定帧续录。

## 安装与更新

适用于 Windows 10 / 11 x64。下载正式版 ZIP，完整解压到可写目录，运行 `Itool/Itool.exe`。操作步骤见包内的 `使用说明.md`。已安装的版本可从主窗口右上角的「检查更新」获取新版。
