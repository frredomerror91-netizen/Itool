# Itool 1.3

Itool 用于查看游戏坐标、搜索目标 ya 的跳跃方案，并在游戏中逐步核对操作结果。

## 启动

下载最新版 Windows 压缩包，解压后运行 **Itool.exe**。请保留同目录的 `_internal` 文件夹。首次启动可选择中文、English 或日本語，之后可在顶部切换。英文和日文也有各自的启动入口。

## 支持的游戏

| 类型 | 当前可用功能 |
| --- | --- |
| I Wanna Maker 已适配版本 | 实时坐标、普通地面 ya 求解、步骤核对 |
| jtool 1.3.6（GMS 1.x VM） | 实时坐标、普通地面 ya 求解、步骤核对 |
| jtool tuhkakuppi 5.2 的 GM8.1 / GMS 程序 | 实时坐标、已支持设置下的普通地面求解、步骤核对 |
| 使用标准 I wanna 跳跃与落地规则的 32位 GMS 1.x VM 游戏，包括 I wanna Lap Around 1.1 | 实时坐标、通过适配检查后的普通地面 ya 求解、步骤核对；支持普通矩形方块的整数倍放大 |
| 未连接游戏 | 自动使用离线 ya 求解 |

自定义物理或尚未识别的脚本、其他 GM8 构建、通用 GMS2、64位 GameMaker 和其他 YYC 游戏目前不保证支持。请以记录起点后的适配提示为准。软件顶部会显示已连接引擎；无法连接时会显示原因。

## 在游戏中使用

1. 启动游戏并进入关卡，再打开 Itool。只有一个可识别游戏时自动选中；有多个时从列表选择。也可点击 **选择进程…** 手动切换。
2. 在普通静止地面站稳，点击 **记录当前坐标**。
3. 输入 **目标 ya**，点击 **开始分析**。
4. 从 **全部备选方案** 选中一个方案，按右侧步骤操作。
5. 每次跳跃后站稳，当前步骤落地 ya 相符时编号和跳法变绿，并自动跟随下一步；不符时变红。按游戏的 **R** 后，重生落地值对应已完成步骤时保留此前绿色，从下一步继续；回到初始起点则从头等待。也可点 **从头核对** 手动清空进度。

步骤核对需保持软件连接同一个游戏。重生后请稍等角色站稳；若多个已完成步骤具有相同落地值，会恢复到最靠后的一步。不对应原方案的位置或切换场景后，应重新记录起点和分析。请在游戏窗口内按R。核对的是落地值，不代表软件识别了全部按键。

## 离线使用

没有连接游戏时直接输入目标 ya 并分析即可，无须选择示例。起点默认 Y=309.399993896484375，界面会标注离线状态。离线结果不会自动完成实机步骤。

## 跳法与设置

- `4f`：按 jtool 的帧数口径完成该跳；一段跳之间先落地。
- `1+3`：按第一项的时机进行首次取消，再过3帧释放下一个映射跳跃键。需先在改键工具中准备多个跳跃键。
- 含二段跳的步骤会列出空中等待时机，请按提示操作。
- 一段跳与二段跳可分别勾选允许帧数。取消组合可设优先、仅允许或排除。
- 输入目标后默认允许误差为目标末位的一个单位，也可自定误差和偏大/偏小方向。
- 排序可选综合推荐、精度优先或少跳优先，立即生效。
- 默认找到100个解自动停止；设为0则手动停止。点击停止后可以修改目标重新分析。
- 左侧滚轮只滚动设置，不更改选项或数字。
- 求解请使用普通矩形静止地面。水、藤蔓、平台、变重力、特殊遮罩、附近天花板或危险物可能需要另行适配；以软件提示为准。
- 标准GMS游戏上方有已识别的静止方块或尖刺时，只保留不进入其范围的跳法。无法安全通过的二段跳可能不会列出。

## 常用操作

**复制坐标**复制当前值；**复制方案**复制选中的完整方案；**导出**保存方案文件。F6记录，F7开始/停止，F8复制方案，快捷键在Itool聚焦时使用。顶部可选明暗主题、语言和保持置顶。

连接不到游戏时，确认游戏已经进入关卡、选中的进程正确，并查看底部提示。角色处于空中、游戏版本未适配或场景不支持时，记录坐标与求解的可用性可能不同。
