# Itool

Itool 是面向 I wanna 关卡分析与 TAS 路线研究的 Windows 桌面工具，支持 GM8、GMS 和 I Wanna Maker（IWM）三种引擎。主要功能包括 YA 跳法求解、地图路线搜索、逐帧回放，以及 Jtool、Maker 和 RMJ 地图转换。

[下载最新正式版（Windows x64）](https://github.com/frredomerror91-netizen/Itool/releases/latest) · [版本记录](CHANGELOG.md) · [SHA-256 校验清单](SHA256SUMS.txt)

## YA 求解与区间分析

YA 表示角色纵坐标的小数部分。在「ya 求解」中指定引擎、起始坐标、目标 YA 和允许误差，可计算满足条件的一段跳、二段跳与多键取消组合。起点支持手动录入，也可从受支持的游戏进程采样。结果列出各跳段的持续帧数、松键时机及到达 YA。

地图路线提供三种 YA 分析，适用条件如下。

| 分析项 | 固定条件 | 结果 |
| --- | --- | --- |
| 本解 YA | 选中路线的逐帧输入 | 该输入序列可以通关的起始 YA 区间 |
| 任意走法 YA | 同一地图、起点条件和输入范围 | 已找到可行走法的起始 YA 区间，可查看各区间对应的输入 |
| 起跳 YA | 选定起跳帧的速度、跳跃资源、持键状态及后续输入 | 保持该路线后半段时，允许的起跳 YA |

地面出生按站稳后的状态分析，空中出生取出生瞬间。界面区分原事件已验证区间、模型推算区间和未判定范围。

## 地图路线求解

「地图求解器（beta）」支持从地图出生点或内置试玩的当前帧开始搜索。以当前帧为入口时，会保留角色位置、速度、跳跃资源和持键状态。粗略求解与精细求解分别保存参数，可设置搜索时限、跳键数量、允许的跳长及多键取消条件。

候选路线经所选引擎从任务入口逐帧回放，抵达目标后列入「可行方案」。每条方案提供通关帧数、跳法摘要、逐帧按键和关键起跳 YA，可回放或导出为 JSON。「继续改进」可在已有方案上搜索更短的路线。「已知最短」表示当前已验证方案中的最少帧数。搜索达到时限时，界面保留已取得的结果。

## 地图编辑、格式转换与录像

- **地图编辑与试玩。** 支持物件摆放、碰撞范围查看、起点与目标编辑、边界设置，以及暂停、变速和单帧推进。地图工程保存为 `.itmap`。
- **地图转换。** 支持读取 Jtool `.jmap`、I Wanna Maker v104 和 RMJ 1.03 `.map`。可按房间预览物件、校正起点与目标并保存为 Itool 工程。转换器会列出尚未支持的物件或跨房事件。
- **录像与回放。** 内置试玩可记录逐帧操作。回放支持时间轴定位、逐帧检查和从指定帧续录，便于比较同一段刺阵的不同操作。

## 运行与资料

适用于 Windows 10 / 11 x64。完整解压发行包后运行 `Itool/Itool.exe`。包内附 `使用说明.md`、示例地图和启动脚本。「IWM 半像素刺缝.cmd」可直接载入对应示例，供路线搜索与回放测试。

各引擎的数值精度、跳跃和碰撞机制另见《I wanna 物理规律与机制》，资料包见对应发行页的 `I.wanna.zip`。[物理机制资料](https://github.com/frredomerror91-netizen/Itool/releases/tag/v1.6.2) · [许可说明](LICENSE.txt)
