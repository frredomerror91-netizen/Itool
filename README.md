# Itool 2.0

Itool 是面向 I wanna 玩家的 Windows 地图编辑与求解工具。你可以摆出一段刺阵，选择 GM8、GMS 或 IWM 规则，在画布里试玩，也可以让程序从出生点或当前帧寻找路线，再逐帧查看按键、坐标和跳跃时机。

**[下载 Itool v2.0.0 正式版 · Windows x64](https://github.com/frredomerror91-netizen/Itool/releases/download/v2.0.0/Itool-v2.0.0-win64.zip)** · [版本说明与校验文件](https://github.com/frredomerror91-netizen/Itool/releases/tag/v2.0.0)

## 第一次求解

1. 在 Windows 10 或 11 的 64 位系统上，把整个 ZIP 解压到一个新文件夹，双击 `Itool/Itool.exe`。软件自带运行依赖，可选简体中文、英语或日语。
2. 想先看一张现成的图，可以直接双击同目录的「IWM 半像素刺缝.cmd」。要解自己的图，在「地图求解器」中打开 `.itmap`，或新建地图、选择引擎并摆放起点、刺和目标。
3. 点「粗略求解」。找到第一条路线后即可选中并「回放」，点「逐帧按键」可查看每一帧的方向、起跳和松键。窄缝或需要精确起跳高度的图可以再试「精细求解」。

## 用 2.0 调一段跳法

- **从卡住的地方接着求。** 在内置试玩中点求解，程序会保留当前坐标、速度和剩余跳跃次数。搜索过程中可以继续编辑，从「任务地图」能回到当时的场景回放结果。
- **检查多键取消。** 求解器会根据角色状态尝试有效松键，包括上升中连续几帧分次松开不同的键。选中路线后点「后台状态」，可以看到这条路线从哪里开始优化、实际省下几帧。「已知最短」是目前通过所选引擎完整回放的最好成绩。预算用完时仍可能有更短路线。
- **限定跳长。** 打开「跳法筛选（内测）」，可分别勾选一段、二段允许的帧数。例如一段只选 4f，搜索会按 4f 尝试该段起跳，空中仍可横移、停步和折返。
- **记录自己的操作。** 试玩时点「录制」开始或结束。打开「录像 / 回放」，可以逐帧前后查看，从选中帧续录，再另存为新录像。
- **分析 YA 或转换地图。** YA 是纵坐标的小数部分。「ya 求解」可分析到达目标 YA 的按键。「地图转换器」可读入支持的 `.jmap` 和 `.map`，选择房间、核对起点和目标后另存为 `.itmap`。引擎或物件不兼容时，按界面提示检查相应物件。

地图引擎各自处理碰撞和跳跃，同一串按键换一个引擎可能会撞刺。完整操作和支持范围见解压目录中的 `使用说明.md`。
