# Itool

Itool 是一款给 I wanna 玩家练跳、解图的 Windows 工具。想调到某个 YA，可以输入当前坐标，让它算出每一跳要按多久。遇到过不去的刺阵，可以导入地图，让它从你卡住的那一帧寻找路线，再逐帧看清方向键和跳键的操作。

**[下载 Windows 64 位便携版](https://github.com/frredomerror91-netizen/Itool/releases/latest)** · [版本记录](CHANGELOG.md)

## 从当前高度跳到目标 YA

YA 是角色纵坐标的小数部分。例如 `Y = 309.4` 时，YA 约为 `0.4`。在「ya 求解」选择 **GM8、GMS 或 IWM**，手动填入起点，或从受支持的游戏进程读取角色坐标。输入目标 YA 和允许误差，就能查找可用的跳法。你可以指定一段跳和二段跳的帧数、允许几个跳键，再查看每段何时起跳、按住多久、何时松开。

## 寻找能通过刺阵的路线

在「地图求解器（beta）」摆放砖、刺、起点和目标，选好引擎，点击「粗略求解」或「精细求解」。也可以先手动玩到难点，再从当前帧接着求。程序会保留当时的速度、可用跳跃次数和持键状态。

- **回放一条路线。** 在「可行方案」里选中跳法，点「回放」看角色怎样过刺。打开「逐帧按键」能查到哪一帧要转向、起跳或松键。每条列出的路线都经过所选引擎从任务起点到目标的回放核验。
- **比较不同跳法。** 可以限制跳长、跳键数量和多键取消，也可以在找到首解后点「继续改进」。界面中的「已知最短」是本次已经验证的最好成绩。搜索超时表示当前预算内尚未找到路线，地图仍可能有解。
- **看一条路线对 YA 有多挑。** 「本解 YA」回答“保持这套按键，哪些起始 YA 还能过？”。「任意走法 YA」允许换一套按键。双击已验证区间可查看对应走法。「起跳 YA」则能单独检查路线里的某一次跳跃。

## 地图编辑、转换与录像

- **编辑与试玩。** 在画布上搭建或修改刺阵，设置边界和目标，直接试玩。可以暂停、单帧推进，对照角色位置、速度和跳跃状态。
- **导入已有地图。** 在「地图转换器」打开 Jtool 的 `.jmap`、I Wanna Maker 或 RMJ 的 `.map`，选择房间，核对起点和目标后另存为 `.itmap`。转换预览会提示需要处理的物件。
- **录下自己的走法。** 试玩时点「录制」，结束后打开「录像 / 回放」。可以拖动到失误前一帧，从那里续录，再另存一个版本比较两次操作。

## 第一次使用

1. 在 Windows 10 / 11 x64 上解压整个便携包，打开 `Itool/Itool.exe`。
2. 想先看一条现成刺阵怎么过，可以双击包内的 **「IWM 半像素刺缝.cmd」**，然后点「粗略求解」。
3. 第一条可行方案出现后点「回放」。要练自己的图，在地图页点「打开」，或从「地图转换器」导入。

完整操作见便携包内的 `使用说明.md`。另有分引擎的物理机制资料和配图，可从资料发行页下载 `I.wanna.zip`。[I wanna 物理规律与机制](https://github.com/frredomerror91-netizen/Itool/releases/tag/v1.6.2)
