# Itool

Itool 是面向 I wanna 玩家和制图者的 Windows 桌面工具。它可以编辑和转换地图，搜索 GM8、GMS 和 I Wanna Maker（IWM）地图中的路线，生成刺阵，并逐帧录制和编辑受支持游戏的 TAS。

[下载最新正式版](https://github.com/frredomerror91-netizen/Itool/releases/latest) · [更新记录](CHANGELOG.md) · [SHA-256 校验](SHA256SUMS.txt)

## 主要功能

- **地图编辑与转换**　编辑物件、查看碰撞范围，或从受支持的游戏读取当前房间。在 Itool、Jtool、I Wanna Maker 和 RMJ 格式间转换时，可并排编辑源图与转换结果。
- **整图求解**　从出生点或试玩暂停帧开始，按所选引擎、房间边界和角色运动参数搜索路线。粗略和精细求解支持地面 A/D 微调 XA、跳跃准备与空中调 YA。
- **路线比较与回放**　比较跳法、查看逐帧输入，回放或导出经引擎核验的路线。可继续改短，并查看当前最短帧数、已知下界与最短性证明状态。
- **YA 分析**　分析一段跳、二段跳和连续取消，查看固定按键、不同走法或指定起跳状态的可行 YA 区间。
- **刺阵生成器**　生成普通或 XA／YA 刺阵。可手摆起终点或全自动出题，通过题号重开、试玩、查看示范，或将题面送入地图求解器。
- **完整游戏 TAS**　为兼容的 GM8 游戏录制和编辑键鼠输入，按帧定位、存读档、比较分支并续录。Simple Needle v1.01 也支持识别已启动的游戏并从头新录。

## 运行环境与许可

适用于 Windows 10 / 11 x64，提供便携版及内置更新。完整游戏 TAS 需要自行准备游戏文件。GM8 录制使用 OpenGMK，其许可随包提供。[软件许可](LICENSE.txt) · [OpenGMK 项目与源码](https://github.com/OpenGMK/OpenGMK)
